## 当前边界

已实现：首页京东 / 美团 / 淘宝 / 拼多多 / 饿了么平台选择，推广商品 / 优选商店 / 领券中心 / 推广专区四模块及四栏导航；首页与领券页共享当前平台、地域 / 业务范围和只读券数据，平台改变清除地域 / 业务选择与旧提示，但不表示渠道已获授权。「我的」保留订单 / AI / 推广入口，订单与 AI 通过二级路由访问；分类 / 省钱旧路由保留，不再占底栏。H5 支持入口、平台选择、地域 / 业务操作和底栏 Enter / Space。商品、店铺、订单、AI 与推广业务仍显示未接入说明；券页区分读取中、无数据、读取错误、服务未接入和平台未开放。微信端虽可编译，SVG 导航图标与实际设备行为仍须单独适配验收。

## 只读券接口契约

M1-01d-1 提供 `src/features/coupons/api.ts`：目录 `/api/v1/coupons`、地域 `/api/v1/coupon-cities`、详情 `/api/v1/coupons/{id}`，仅 GET，uni-app 请求超时 10 秒，无内置令牌或授权头。平台映射 JD / TAOBAO / MEITUAN → JD / TB / MT；PDD / ELEME 保持未开放，不发请求。只接受成功信封、完整字段、当前平台与地域 / 业务范围、非过期材料及一致的领取模式标签；错误不展示服务器内部信息。

M1-01d-2 将契约连接首页摘要（最多两条）与领券页；地域选项只使用服务器结果，未选城市时只显示不限城市活动，选城市后仍包含不限城市活动；业务留空只显示不限业务活动。切换平台 / 地域 / 业务先清空列表、详情与游标，旧响应不能回填。地域初次加载失败时仍可读取不限城市活动；已有明确城市选择不因暂时地域错误擅自改变。详情只显示规则和更新 / 有效期，目录与详情可显式重试；更多页失败保留同一游标重试，到期数据会隐藏并失效详情。

不提供领取 / 购买能力，不使用商品示例或虚构券作为生产兜底。H5 生产产物使用同源 `/api/v1/...` 路径，需要部署方正确配置 API 路由；本轮没有生产部署或现有数据库迁移。跨端编译不表示相对 API 路径、微信合法域名或实际设备已验收；真实渠道及数据验收仍独立进行。

`npm run build:mp-weixin` 仅供后续编译检查，不能代替真实微信 AppID、合法域名配置、开发者工具和设备验收；manifest 中不填假 AppID。
