# 万惠宝客户端工程设计

日期：2026-09-17。关联任务 M0-02b；用户已确认 uni-app（Vue 3 + TypeScript）、H5 首发、工程布局及数据流，并明确要求后续自行判断、不再逐项询问。

## 范围与架构

工程位于 `apps/client`，不改 Go 服务领域规则。采用 uni-app Vue 3 CLI 工程，TypeScript 严格检查，npm 锁文件固定依赖；先验收 H5，再单独验收微信小程序。消费者保留首页 / 分类 / 省钱 / 订单 / 我的五个导航；推广中心作为独立页面入口，不与消费者底栏混用。

本子项目先交付可运行工程、首页双卡和「我的」推广入口（M0-02c、M1-01）。申请状态分流、申请表、推广位、预览、转链和分享属于后续逐任务交付，不以首页工程完成替代整个推广模块完成。分类、省钱、订单、我的尚无真实数据的区域采用明确未接入状态，不生成虚构商品、金额、订单或收益。

## 视觉与组件

参考 `docs/images/home-promoter-entry-v2.png`，原生组件重现搜索、四渠道行、AI / 推广双卡、推荐区域和五栏导航。品牌统一「万惠宝」，不模拟操作系统状态栏。

背景暖白 `#f7faf8`、正文深绿 `#123c34`、主色 `#07594b`、薄荷区 `#eaf6f0`、优惠区 `#fff1e7`；文字使用系统中文字体。字号：品牌 26px、区标题 23px、正文 15px、辅助 13px；行高至少 1.4。边距 18px，间距 12 / 18 / 24px，卡片圆角 18px。双卡保持等宽，320px 窄屏可换行文字而不横向溢出。触控区域至少 44px，底栏避让安全区；宽屏居中且不拉伸手机信息布局。

导航与功能图标用一致的线性 SVG 资源；渠道入口暂用文字标识，不复制未获授权商标资产。真实商品及外卖素材尚未授权且 API 未提供，故推荐区改为「商品推荐暂未接入」，不将整张设计截图当客户端。明确允许新增未接入解释文字，这是数据真实性所需的设计差异。

组件职责：App 只承载全局样式；各页面承担自己的内容；FeatureCard 负责双卡；UnavailableState 负责空态；静态路由与导航由 pages.json 管理。公共 API 客户端独立于页面，跨端请求使用 uni.request，页面不得拼接身份或自行认定资格。

## 数据、安全与异常

后续 API 层连接现有 Go 接口，只使用受控身份提供方签发的访问令牌；不内置令牌、私钥、生产凭据，不从 URL 接收令牌。真实登录未接入时显示说明并关闭身份业务提交。服务端审核 / 资格 / 渠道状态为唯一依据。

变更请求按逻辑操作保存幂等键，超时使用原键；转链不确定结果仅查询 `/api/v1/promotions/convert/{id}`，不得自动再次创建。分享读取 `/api/v1/promotion-links/{id}/share-artifacts`，复制实际成功后报告 share-events，eventId 等于 Idempotency-Key；遥测失败不能把复制结果改成失败，不声称送达或成交。

首批工程不启用演示业务数据，也不声称接通上述受限接口。未来演示模式须显式标识且与真实 API 隔离。网络错误保留输入并提供受控重试；401 回到真实登录边界，409 展示状态冲突，503 提示暂不可用；不对外显示内部错误原文。

## 验收

工程：npm ci、npm test、npm run typecheck、npm run build:h5 均成功，锁文件与产物隔离；工程说明包含启动命令及真实依赖限制。

首页：双卡可操作，「我的」推广入口可到达同一推广页面，五栏可切换；搜索和渠道未接入时明确提示，没有假结果。单元测试与浏览器测试覆盖导航、功能入口、空态，320px / 390px / 宽屏无横向溢出。浏览器对照 V2 记录布局、颜色、字号、双卡、底栏至少五项证据与上述有意差异。

真实登录、微信设备行为、京东渠道、订单、资金和生产发布分别验收，均不是本子项目已完成条件的替代品，完整研发目标仍保留这些任务。
