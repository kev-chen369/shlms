# 管理后台设计

- 总览：GMV、有效订单、佣金、返现、毛利、退款率、漏单率和同步延迟。
- 渠道：账号状态、推广位、权限清单、健康检查、同步水位与熔断。
- 商品/活动：上下架、排序、地域、终端、有效期和内容审核。
- 订单/佣金/对账：原始数据、标准化结果、状态时间线和差异处理。
- 钱包/提现：只读流水、冻结、审批和付款结果；不提供直接改余额。
- 客服/风控：漏单申诉、证据、风险命中和处置记录。

采用 RBAC 和最小权限。财务、风控、客服、运营和渠道管理员职责分离；密钥仅允许受限角色轮换。资金、密钥、佣金规则、封禁和人工归因操作记录前后值、操作者、审批者与原因。

## 推广中心后台配套（待开发）

增加推广申请审核、推广员停用与原因、内部推广位和外部渠道位配置、推广订单归因查询、收益与结算批次核对。审核提交须携带版本号，重复提交幂等；渠道管理员配置映射，财务核对结算，客服只在授权范围查看脱敏数据，均记录审计。

推广用户端已有核心图稿，审核后台的专用交互稿仍待补齐，纳入[研发计划 M0 / M1](./superpowers/plans/2026-09-16-promotion-center.md)。接口与数据边界见[推广中心详细设计](./21-promotion-center-detailed-design.md)，不允许通过后台直接改钱包余额或伪造归因证据。
