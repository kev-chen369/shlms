# AI 全场景省钱生活平台产品总设计 V1.1

## 产品定位

聚合电商、外卖、本地生活和票务优惠，以真实商品与活动数据完成比价、领券、转链和订单归因；上游结算佣金后，平台按规则向用户返现。

## 用户、终端与核心域

- 普通用户搜索优惠、比价、查看返现与提现；VIP 在毛利约束内获得更高返现。
- 推广员/达人使用独立推广标识，只做一级推广收益。
- 运营、客服、财务、风控和渠道管理员通过 RBAC 后台协作。
- 终端为微信小程序、H5/App、管理后台；V1 不自建商城结算。
- 核心域包括用户、目录、搜索、渠道适配、Tracking、订单、佣金、钱包、提现、对账、风控和运营。

统一 `ChannelAdapter` 隔离渠道差异；统一模型计算“实际成本 = 支付价 - 券 - 预计返现”。AI 只负责理解、排序和解释，价格必须来自带时效的数据源。

## 版本边界

- V1：京东/PDD 商品，美团/饿了么活动导购；跑通订单、佣金、钱包和提现。
- V2：电影票导购、更多本地生活、价格提醒与推荐增强。
- 暂不做站内选座出票、自营库存、多级分销、复杂积分商城和 AI 自造价格。

## 原则

预估佣金不入可提现余额；保存渠道原始订单；订单、钱包和提现均需幂等；人工资金操作双人审批并审计；密钥仅进入密钥管理系统。
