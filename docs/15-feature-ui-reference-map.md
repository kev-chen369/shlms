## 使用规则

1. 功能评审时先按功能编号找到详细设计，再打开对应参考图定位页面与状态。
2. 图片负责视觉方向和信息层级，字段、状态、权限、幂等与结算规则以研发文档为准。
3. 标为“部分覆盖”的功能在进入前端开发前补充线框图、状态表或专属 UI 图。
4. 渠道入口必须由后台配置和权限状态控制；未获批、过期、熔断或维护中的渠道不得显示为可交易状态。
5. 所有金额均标注预计或实际属性，所有外部交易按钮均提示即将前往合作平台。
