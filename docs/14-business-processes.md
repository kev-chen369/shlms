# 完整业务流程

## 搜索与购买

用户需求 → 并行查询缓存/渠道 → 标准化、去重与排序 → 展示券后价和预计成本 → Tracking → 渠道转链 → 第三方成交。

V3 领券入口的补充路径：选择平台 / 券 → 核实适用商品与领取资格 → 取得领取回执 → 「去使用」到本站商品详情（多商品券先到适用列表）→ 复核价格与券规则 → 购物 Tracking / 安全跳转 → 第三方下单。领取、打开商品、跳转和成交分别记状态；外部领券页打开不等于领取成功，点击不等于订单回流。细节见[领券到下单设计](./22-coupon-to-purchase-design.md)。

按真实券能力分流：仅本站可核实领取时走上述回执路径；平台领券、商品加券与美团活动先生成受控承接地址，用户在平台领券、支付或到店核销。App / H5 / 小程序按获批终端能力回退；页面已打开、领取、支付、订单归因与核销各自需要证据，返站不自动推进状态。

## 订单与返现

接收渠道订单 → 保存原始数据 → 幂等标准化 → 精确归因 → 展示预计返现 → 渠道确认佣金 → 待结算 → 实际结算 → 钱包可用余额。

## 退款与提现

退款事件更新退款明细并调整佣金；未入账返现失效，已入账则生成独立扣回流水，不删除原流水。

提现为：校验实名/限额/余额 → 冻结 → 风控 → 审批 → 支付 → 成功结转或失败解冻 → 通知与日终对账。

## 漏单与故障

漏单申诉需提交渠道、订单号和证明，经查重和审核后建立带审计的归因；无法证明归属时不得入账。

渠道失败率超阈值后熔断并降级，恢复时先探测、小流量放开，再补同步缺失窗口。

## 推广中心业务链路

首页 / 我的入口 → 登录与申请审核 → 内部推广位及渠道配置 → 商品识别预览 → 服务端复核 → 幂等 Tracking 与转链 → 链接 / 文案分享 → 渠道订单同步 → 精确推广归因 → 规则快照与收益确认 → 渠道结算 → 分来源钱包流水 → 提现与对账。

推广身份停用禁止新转链但保留历史；匿名购买者不可仅凭推广者身份自动领取消费者返现；分享事件不触发奖励；退款按未入账调整或已入账冲正处理。具体状态与异常补偿见[推广中心详细设计](./21-promotion-center-detailed-design.md)。

## 完成定义

只有注册、搜索、Tracking、跳转、测试成交、归因、佣金确认、退款、结算、返现、提现及对账均有证据，才算 V1 业务闭环完成。
