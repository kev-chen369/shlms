# 用户端 UI 与交互规范

一级导航为 `首页 / 分类 / 省钱 / 订单 / 我的`。首页包含城市、搜索、渠道入口、活动、爆款和 AI 比价入口。

- 搜索列表：平台、券后价、预计返现、实际成本、销量与配送，可按实际成本排序。
- 商品详情：价格时效、优惠券、返现说明、跨平台比较、收藏、分享与领券购买。
- 省钱中心：外卖红包、大额券、高返、新人和限时活动。
- 订单：按预计返现、待结算、已到账、无效/退款分组，展示状态解释。
- 我的：预计、待结算、可提现、累计省钱、邀请、客服和设置。

每页定义加载、空、错误、离线、权限不足、活动过期和渠道不可用状态。金额旁明确“预计/实际”和更新时间；关键操作不能只靠颜色区分。触控区域不小于 44px，并支持字体缩放。

## 推广中心与首页入口 V2

### 多平台首页 H5 新方案（V3，待产品评审）

2026-09-17 用户提出以平台品牌（京东、美团、淘宝等）为首页一级选择。选中平台后，首页按「推广商品 / 优选商店 / 领券中心 / 推广专区」呈现该平台内容；底部固定四栏「首页 / 领券 / 推广 / 我的」。平台切换只改变内容上下文，不应将未接通的平台描绘为已有真实商品、券或转链能力。模块无数据时展示明确空态与开通状态，不以演示数据填充生产页面。

![多平台首页 H5 V3 概念稿](./images/home-platform-modules-h5-v3.png)

本图以京东选中为示例；商品、店铺、价格、券额均为虚构占位。旧版五栏「首页 / 分类 / 省钱 / 订单 / 我的」及 AI / 推广双卡图稿保留作为 V2 历史方案；V3 四栏是本次新提案，尚未完成产品评审、前端实现或真实渠道验收。若采纳 V3，需同步修订下述 V2 规则及其他文档中的五栏表述。

首页按「搜索 → 渠道快捷入口 → AI 帮我选 / 推广赚钱双卡 → 商品推荐 → 外卖红包」排列，保留现有底部五栏。「我的」提供次入口。点击后根据登录、申请、审核、启用、停用状态分流；详情见[模块设计与全部图稿](./21-promotion-center-detailed-design.md)。
