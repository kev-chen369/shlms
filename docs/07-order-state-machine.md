# 订单、归因与状态机

主状态：`CREATED → PAID → CONFIRMED → COMMISSION_CONFIRMED → SETTLEMENT_PENDING → SETTLED`。异常终态包括 `CANCELLED`、`INVALID`、`REFUNDED`；部分退款保留主订单并记录退款与佣金差额。

处理流：渠道响应 → 原始订单 → 标准化 → 幂等写入 → 归因 → Outbox 事件 → 佣金、返现与通知订阅处理。

归因优先级为精确渠道子标识 > 独立推广位 > 用户申诉证据。禁止仅凭相近时间和金额自动归因；低置信度订单进入人工审核。

状态只允许适配器映射表定义的边转换。乱序事件保留但不回退已确认状态，退款与冲正走专用事件。每次变化记录来源、前后状态、渠道时间和处理时间。
