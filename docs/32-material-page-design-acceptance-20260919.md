## 交付范围与环境

M7-01e-1～3交付本人只读目录前端契约、状态、推广位选择、实际页面与入口、详情复核、错误 / 空 / 未开放 / 分页及隔离。不是取链 / 分享流程完成，也不是正式身份、渠道来源、生产发布或微信真机验收。API只读获批的安全投影，不根据客户端时间或内部位配置擅自推断生成权限。

流程：推广中心键盘入口 → 注册选品页 → 未登录不请求；测试端向同一页面提供身份 → GET本人已启用位 → 明确选择及确认服务端scene / 可选城市与业务 → 读取当前范围目录 → 独立查看最新详情；切平台 / 类型 / 身份清旧范围。淘宝 / 美团缺本人映射时未开放，不复用京东位。

本机 `http://127.0.0.1:5173`，现有 Chrome / Playwright；Browser plugin not available，按前端测试技能使用既有浏览器回归。测试端注入合成session Ref并拦截真实uni GET，不替换生产模型，不签发真实身份，不请求真实渠道。当前产品身份默认null；正常访问只显示登录缺失，不会出现下列合成目录。

## V3设计对应与有意差异

主代理直接查看[选品V3概念图](./images/promotion-materials-h5-v3.png)，保留原图作设计参考，不用实现截图覆盖概念图。

| V3要素 | 当前实现证据与差异 |
| --- | --- |
| 薄荷绿色标题区、白底卡片、橙色原因提示 | 正常组件与完整页面保持颜色层次、圆角卡片 / 输入及焦点描边；未复制概念装饰插画与字体细节，不宣称像素级视觉一致 |
| 京东 / 淘宝 / 美团与商品 / 活动 | 保留平台 / 类型控制；未开放平台可点开原因说明，不伪装有目录；美团商品显式禁用且键盘不能绕过 |
| 商品 / 活动区别 | 当前以类型切换独立读取，不在商品目录插入演示活动专区；活动显示startsAt及完整范围，商品不冒充活动 |
| 每条查看 / 生成 | 实际卡片逐条查看并重新GET详情，生成灰色禁用；CATALOG READY不代表可转链 |
| 商品图、价格 / 券与营销副标题 | 当前安全公开API没有这些字段；不填概念保温杯、毛巾、图片或预计收益。后续可信渠道报价 / 图片能力另按计划接入 |
| 确认物料与推广位 | 当前明确选本人位 / 服务端scene后读取目录，详情在页内展开；不是完整独立预览确认 / 转链页面。避免先读无位范围，不免除服务端核验 |
| 顶部品牌 / 搜索壳 | 独立custom导航详情页不复制概念搜索壳；document title为当前万宝单生活，概念图旧惠省生活为历史名称 |
| 一级四底栏、流程条与链接记录 | 一级首页 / 领券 / 推广 / 我的保持不变；选品作为详情路由通过明确按钮返回推广。没有复制装饰性流程条或未完成的记录入口，生成 / 分享 / 记录由对应任务继续 |

这些对应只说明当前只读范围，不替代REL-01产品视觉验收或所有P编号页面完成；装饰、完整营销壳及后续生成体验不得被此记录抹除。
